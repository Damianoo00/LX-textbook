# Scenariusz działania

| Etap | Dlaczego | Jak / akcja | Co się zmienia / obserwacja |
|---|---|---|---|
| Przygotowanie | określić zakres | użytkownik tworzy brief | znane wejścia i wyłączenia |
| Instalacja | dopasować format klienta | dry-run, potem kopia plików | natywne role i skill dostępne |
| Badanie | uniknąć fikcyjnych faktów | researcher weryfikuje źródła | mapa z dowodami i lukami |
| Projektowanie | zapewnić spójność przyczynową | designer pisze ścieżkę/storyboard | specyfikacja prognozy, transferu i modelu |
| Bramka planu | zapobiec implementacji wadliwego planu | reviewer ocenia dowody | jawne pass/fail/pending |
| Przekrój | sprawdzić pełną lekcję | implementer buduje model i assessment | runnable pionowy przekrój |
| Pełen zakres | spełnić brief | rozszerzenie po przekroju | ukończony zakres |
| Walidacja | ocenić działanie | testy, desktop/mobile, poprawki | raport dowodów i ograniczeń |

Wizualizacje i ruch definiuje storyboard konkretnego modułu; sam pakiet nie zawiera animacji ani symulacji dydaktycznej.
