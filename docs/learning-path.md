# Ścieżka wdrożenia mechanizmu

Cel użytkownika: przechować samodzielny pakiet w GitHub, zainstalować go w projekcie i użyć tej samej kolejności bramek w trzech harnessach.

Sekwencja: poznaj wspólny kontrakt → obejrzyj role → wybierz adapter → dry-run instalacji → instalacja → własny brief → prompt → plan i recenzja → przekrój → rozszerzenie → testy i przegląd wizualny.

Przykład rozwiązany: README pokazuje instalację wszystkich adapterów do pustego projektu. Sprawdzenie prognozy: istniejący AGENTS.md ma wywołać odmowę bez zmian; test kolizji potwierdza to zachowanie.

Ocena: poprawne discovery ról/skilla, widoczne narzędzia MCP, brak nadpisania, poprawna kolejność planu przed kodem, jawne dowody każdej bramki. Transfer: zmień temat i harness bez przenoszenia autoryzacji A–D ani twierdzeń neurobiologicznych.

Czas 5–10 minut i symulacja dotyczą przyszłej lekcji, nie instalatora pakietu.
